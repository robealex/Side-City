# Side City

Juego 2D horizontal de construir y administrar una ciudad, en pixel art. Un solo archivo HTML, sin dependencias.

- Mover: flechas o A/D
- Lanzar moneda: Espacio
- Construye casas, mercados, parques y granjas; mejora la alcaldia; ajusta los impuestos y paga el mantenimiento.

Deploy en Vercel: proyecto estatico, sin build; `index.html` en la raiz.
